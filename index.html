Update your MeowKit

Latest stable version: v1.0.3

Enter download mode, then install the latest official firmware from your browser.

Get MeowKit ready

The screen stays off in download mode. That is expected.

  1. 1

    Power off MeowKit and disconnect the USB cable.

  2. 2

    Use a Dupont jumper wire to hold the rear BOOT button. Keep holding BOOT, press and hold the power button for 1–2 seconds, then release the power button. Release and remove the jumper wire.

  3. 3

    Connect MeowKit to your computer with a USB data cable.

Install firmware

Keep MeowKit connected until installation finishes.

Use Google Chrome or Microsoft Edge on a desktop computer. Firmware installation requires HTTPS.
Select USB JTAG/serial debug unit (COMxx) when asked, then follow the on-screen instructions. Erase device removes saved settings and stored data.
